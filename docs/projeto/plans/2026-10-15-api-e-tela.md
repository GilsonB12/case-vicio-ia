# API REST e tela de revisão: plano de implementação

**Goal:** Entregar a API FastAPI da seção 13 da spec e a tela de revisão da seção 14, ambas funcionando com dados simulados agora e com os reais depois, sem nenhuma mudança de código.

**Architecture:** A API reutiliza o pipeline por um serviço com carga preguiçosa (árvore, embeddings, índices, classificadores, limiares) e expõe três rotas. A tela é um app Vite + React + TypeScript que lê arquivos estáticos em `public/dados/` (copiados do repositório por um script npm) e, na falta deles, `public/dados-exemplo/`; mostra a fila de `revisar` e exporta as decisões do professor em CSV. Nenhum backend para a tela.

**Tech Stack:** fastapi, uvicorn, httpx (TestClient); Node 24, Vite, React 18, TypeScript, papaparse, vitest.

**Spec:** `docs/projeto/specs/2026-10-14-classificacao-topicos-design.md`, seções 13 e 14.

## Global Constraints

- Português em código, comentários, textos de tela, testes e commits; identificadores sem acento; commits sem trailers; `git add` por caminho explícito; `node_modules/` e `revisao-ui/dist/` já estão no `.gitignore`.
- Testes nunca chamam API de modelo nem Weaviate: na API, o serviço é substituído por um dublê; na tela, vitest usa dados em memória.
- A API devolve 503 com a mensagem de `ChaveAusenteError` quando não há chave nem cache para a questão; nunca devolve 500 por falta de chave.
- Formato das respostas e dos arquivos lidos pela tela é exatamente o dos intermediários já existentes (`candidatos_questoes_p2.jsonl`, `votos_llm_questoes.jsonl`, `decisoes_questoes.jsonl`, `publicacao.csv`, `questoes.jsonl`, `temas.csv`).
- Suíte Python (`uv run pytest -q`) e suíte da tela (`npm test` em `revisao-ui/`) verdes e sem avisos.

## Review Focus

1. Questão enviada à API sem `alternativas` ou com `comando` nulo: validação Pydantic devolve 422 com mensagem clara, não 500. Teste na Tarefa 1.
2. Serviço construído a cada requisição (lento e caro): carga preguiçosa única, testada por contagem de construções. Tarefa 1.
3. Tela sem dados reais nem exemplo: mensagem amigável em vez de tela branca. Tarefa 2.
4. CSV exportado pela tela com `;` dentro de motivo ou texto quebrando colunas: papaparse com quoting; teste de ida e volta. Tarefa 2.
5. Caminho de tema trocado para id inexistente ou não publicável na tela: a lista de troca só oferece temas publicáveis. Tarefa 2.

### Task 1: API FastAPI

**Files:**
- Create: `api/__init__.py`, `api/servico.py`, `api/main.py`, `tests/test_api.py`
- Modify: `pyproject.toml` (dependências `fastapi>=0.115`, `uvicorn>=0.30`; dev `httpx>=0.27`), `README.md` (seção "API")

**Interfaces:**
- `api/servico.py`: `class Servico` com `__init__(self)` que não carrega nada; propriedades preguiçosas `arvore`, `embeddings`, `indice_temas`, `indice_corpus` (None sem corpus), `classificadores`, `limiares`, `template`; método `classificar(enunciado_html: str, comando: str, alternativas: dict[str, str]) -> dict` que monta o texto (`classificador.dados.montar_texto`), busca candidatos (`candidatos.buscar_candidatos`), colhe os dois votos (`ClassificadorLLM.classificar`), o voto de vizinhança (`vizinhanca.votar_vizinhanca`, nulo sem corpus), decide (`decisao.decidir`) e devolve `{"decisao", "tema_central_id", "caminho" (ou null), "extras_ids", "confianca", "motivo", "regra", "candidatos": [{tema_id, caminho, origem, similaridade}], "votos": {"openai": dict|null, "anthropic": dict|null, "vizinhanca": dict}}`; método `saude() -> dict` com `{"chaves": {"openai": bool, "anthropic": bool}, "weaviate": bool (conexão tentada com USAR_WEAVIATE respeitado), "corpus": bool, "cache_votos": int (arquivos em data/cache/llm), "limiares": dict}`; método `temas() -> list[dict]` com `tema_id, caminho, nivel, disciplina` dos publicáveis.
- `api/main.py`: `app = FastAPI(title="Classificador de tópicos")`; `servico = Servico()` no módulo; modelos Pydantic `Entrada(enunciado_html: str, comando: str = "", alternativas: dict[str, str])`; rotas `GET /saude`, `GET /temas`, `POST /classificar`; `ChaveAusenteError` vira `HTTPException(503, detail=str(erro))`.
- Execução: `uv run uvicorn api.main:app --reload --port 8000`.

### Task 2: Tela de revisão

**Files:**
- Create: `revisao-ui/` via `npm create vite@latest revisao-ui -- --template react-ts` (ou equivalente não interativo), depois `src/tipos.ts`, `src/dados.ts`, `src/exportar.ts`, `src/App.tsx`, `src/App.css`, `src/dados.test.ts`, `src/exportar.test.ts`, `scripts/copiar-dados.mjs`, `public/dados-exemplo/` (publicacao.csv, questoes.jsonl, temas.csv, decisoes_questoes.jsonl, votos_llm_questoes.jsonl, candidatos_questoes_p2.jsonl com 6 questões inventadas, 4 delas `revisar`, usando ids de temas reais da árvore)
- Modify: `README.md` (seção "Tela de revisão")

**Interfaces:**
- `src/tipos.ts`: `Questao {id, enunciado_html, comando, alternativas}`, `Tema {tema_id, caminho, nivel, disciplina, ativo}`, `Decisao {id, decisao, tema_central_id, extras_ids, confianca, motivo, regra}`, `Votos {id, openai, anthropic}` (voto com `tema_central_id, extras_ids, disciplina, confianca, justificativa`), `Candidato {tema_id, origem, similaridade}`, `DecisaoProfessor {id, acao: "confirmar" | "trocar" | "fora", tema_id: number | null, observacao}`.
- `src/dados.ts`: `carregarTudo(base: string): Promise<Conjunto>` que busca `${base}/publicacao.csv`, `questoes.jsonl`, `temas.csv`, `decisoes_questoes.jsonl`, `votos_llm_questoes.jsonl`, `candidatos_questoes_p2.jsonl`; `parseCsv`, `parseJsonl` puros e testáveis; `temasPublicaveis(temas)` exclui raízes (nível 0), inativos e os que têm descrição vazia (o CSV tem a coluna `descricao`).
- `src/exportar.ts`: `montarCsvProfessor(decisoes: DecisaoProfessor[]): string` com cabeçalho `id,acao,tema_id,observacao`, quoting por papaparse; `baixar(nome, conteudo)` cria o link de download.
- `src/App.tsx`: ao montar, tenta `carregarTudo("/dados")` e, em falha, `carregarTudo("/dados-exemplo")`, mostrando um aviso "usando dados de exemplo"; lista à esquerda com as questões `revisar` (id, início do enunciado, tema sugerido, confiança, motivo), painel à direita com enunciado limpo e alternativas, sugestão com caminho completo, as duas justificativas dos modelos com o tema que cada um escolheu, a lista de candidatos com caminho; ações: Confirmar, Trocar tema (select com os candidatos e um campo de busca sobre todos os publicáveis), Fora, campo de observação; contador de revisadas; botão Exportar CSV. Textos em português. Sem rotas.
- `scripts/copiar-dados.mjs`: copia `../publicacao.csv`, `../anexos/questoes.jsonl`, `../anexos/temas.csv`, `../data/intermediarios/{decisoes_questoes,votos_llm_questoes,candidatos_questoes_p2}.jsonl` para `public/dados/`, pulando os que não existem com aviso; `package.json` ganha `"dados": "node scripts/copiar-dados.mjs"` e `"test": "vitest run"`.
